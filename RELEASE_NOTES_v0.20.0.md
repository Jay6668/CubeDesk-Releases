# CubeDesk 0.20.0

Windows x64 single-file desktop release.

## Install

Download `CubeDesk-0.20.0-Windows-x64.exe` from the release assets and run it. No installer wizard is included.

## Requirements

Windows 10 or 11 (64-bit) with Microsoft Edge WebView2 Runtime. A Bluetooth adapter is needed only for smart-cube connection.

Core features and bundled media work offline. Bluetooth connection requires local Bluetooth hardware; it does not require an internet connection.
