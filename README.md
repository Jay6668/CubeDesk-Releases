# CubeDesk

CubeDesk is a Windows desktop application for Rubik's Cube timing, practice, and local solve records.

## Download

Open **Releases**, download `CubeDesk-0.20.0-Windows-x64.exe`, then run it. This is a single-file application; it does not use an installer wizard.

## Requirements

- Windows 10 or 11, 64-bit
- Microsoft Edge WebView2 Runtime
- Bluetooth is needed only when connecting a smart cube

Core timing, practice, analysis, and bundled effects work offline. Bluetooth device connection still requires a Bluetooth adapter.

## Release integrity

Each release includes a SHA-256 checksum file. Verify the downloaded file before running it.

This repository is for application downloads. The source code is maintained separately in a private repository.
